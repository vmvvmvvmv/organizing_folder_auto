# 한국어 OCR 모델

`kor.traineddata`는 [tessdata_fast 4.1.0](https://github.com/tesseract-ocr/tessdata_fast/tree/4.1.0)의 한국어 모델입니다. 이 폴더에 `kor.traineddata`라는 이름으로 넣으세요. 모델 파일은 `.gitignore`에 포함돼 GitHub에 올라가지 않습니다.

앱을 소스에서 실행할 때는 Tesseract에 한국어 데이터가 설치돼 있으면 로컬 모델 없이도 사용할 수 있습니다. Windows 실행 파일을 만들 때는 이 폴더의 모델이 필요합니다.
